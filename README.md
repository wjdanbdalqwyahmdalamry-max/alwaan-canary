# نظام مصنع ألوان الكناري — Enterprise 4.0

نظام صناعي متكامل يجمع MES + CMMS + HR + Inventory + Procurement + QMS + HSE + Alerts + Analytics.

## تشغيل سريع
1. `npm install`
2. `npm start`
3. افتح `http://localhost:3000`

## نشر
يمكن نشره على Render كـ Node Web Service. `Start Command: npm start`.

## قاعدة البيانات
`database/schema.sql` مخطط PostgreSQL موسع. الواجهة الحالية تعمل كـ Enterprise UI/Demo مع تجهيز API ونقطة صحة، ويجب ربط PostgreSQL والمصادقة والتخويل قبل الاستخدام الإنتاجي الفعلي.
